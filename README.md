# DP-800 Exam Quest

A gamified practice exam for **Microsoft DP-800: Developing AI-Enabled Database Solutions**.

▶ **Play: https://abdelrahmanfekryy.github.io/dp800-exam-quest/**

- 909 questions, each placed under one of the 3 official exam domains:
  - Design and develop database solutions (35–40%)
  - Secure, optimize, and deploy database solutions (35–40%)
  - Implement AI capabilities in database solutions (25–30%)
- Exam simulation in 3 weighted sections, with a score out of 1000 per domain and overall (700 to pass)
- Domain drills, mistake review, and a searchable study bank
- The answer is hidden under every question: check your answer or click to reveal it
- XP, levels, combos and badges. Progress stays in your browser.
- **Service exams**, kept separate from the DP-800 exams, each covering one technology A to Z (beyond what DP-800 tests):
  - **T-SQL** (280 questions), written from the study repo's T-SQL notebook
  - **Azure OpenAI & Foundry** (139 questions in 12 sections), written from the Microsoft Learn docs, with a source link under every answer
  - **Data API builder** (64 questions in 11 sections), from the Learn docs
  - **SQL Projects & SqlPackage** (35 questions in 6 sections), including GitHub Actions deployments
  - **Entra ID, Managed Identity & Key Vault** (23 questions in 6 sections)
  - **Event-driven integration** (21 questions in 4 sections): Functions SQL bindings, CES, Logic Apps, Event Hubs, Service Bus
  - **Azure SQL platform** (18 questions in 5 sections): tiers, serverless, pools, HA/DR, backups, networking, tuning
  - **Azure Monitor & KQL** (14 questions in 5 sections)
  - **GitHub Copilot & MCP** (10 questions in 5 sections), from the GitHub and Learn docs
